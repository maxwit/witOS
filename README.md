<h1> witOS</h1>

A SM$^2$ (smart and small) RTOS for AIoT devices.

# Build

```shell
make list-defconfig # check available boards (optional)
make <board>_defconfig # Pls replace <board> with a real board name, i.e. omap3530)
# or
make menuconfig

# then
make
```
# Clean
```shell
make clean
# or
make distclean
```
